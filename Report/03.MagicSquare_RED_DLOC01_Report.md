- PRD §3.1에는 **미등재** — R-01·R-05·Report/02 1-index 계약으로 근거

## 4. D-LOC-01 스켈레톤

### 4.1 테스트 본문

- **파일:** `tests/entity/test_d_loc_01.py`
- **함수:** `test_d_loc_01_blank_coords_row_major(grid_g1)`
- **AAA 주석:** Given / When(`find_blank_coords`) / Then `[(2,2),(3,3)]`
- **Then 실행:** `pytest.fail("RED: D-LOC-01 — 구현 없음, 의도적 실패")` 한 줄만
- **금지 준수:** assert 본문·skip·xfail·통과 더미 없음

### 4.2 픽스처 `grid_g1`

```text
[ 1,  2,  3,  4]
[ 5,  0,  7,  8]
[ 9, 10,  0, 12]
[13, 14, 15, 16]
```

- `0` 위치: 1-index **(2,2)**, **(3,3)**
- 상수: `entity.constants` import (`BLANK_CELL`, `GRID_SIZE`)

### 4.3 패키지 충돌 해결

`tests/entity/__init__.py` 존재 시 pytest가 `entity`를 `tests/entity`로 해석 → `entity.constants` ImportError.  
Harness `__init__.py` 제거 후 `src/entity` import 정상화.
