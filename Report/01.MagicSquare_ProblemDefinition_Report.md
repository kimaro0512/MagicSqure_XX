## 1. Executive Summary

4×4 부분 마방진(빈칸 2개, 1~16, 합 34)을 다루는 학습자는 **행·열·대각선 검증을 빠뜨린 채 “완료”로 판단**하고, 틀림이 드러난 뒤 **시간을 헛수고**로 잃는다.  
MagicSquare_XX의 1차 문제 정의는 **풀이·앱이 아니라 “검증 누락 → 잘못된 완료 판정 → 시간 손실”** 에 둔다.

## 4. 문제 정의

### 4.1 진짜 문제 (한 문장)

**4×4 부분 마방진을 풀 때 행·열·대각선 중 하나라도 검증에서 빼먹으면, 이미 맞췄다고 판단한 뒤 시간을 쓰게 되고, 틀림이 드러나면 그 시간이 전부 헛수고가 된다.**

### 4.2 표면 문제 (잘못된 정의 — 프로젝트에서 사용 금지)

| 표면 문제 | 왜 잘못됐는가 |
|-----------|---------------|
| ~~4×4 마방진 검증 프로그램을 만든다~~ | 솔루션을 문제로 착각 |
| ~~대각선까지 자동 체크하는 앱/기능이 필요하다~~ | 미래 가정·기능 착각 |
| ~~TDD로 마방진 솔버를 만들면 실수하지 않는다~~ | TDD·솔버를 문제 정의에 섞음 |

### 4.3 문제 → 결과 체인

```
검증 조건 누락 (특히 대각선 1개)
    ↓
잘못된 "완료" 판정
    ↓
추가 시간 투입 (예: 20분)
    ↓
틀림 발견 → 시간 전부 헛수고
```

## 7. 가설 (검증 전 — 확정 아님)

1. 학습자는 행·열만 확인하고 대각선 1개를 자주 빠뜨린다.
2. “완료” 판정 전 10선 전체 검증이 없으면 20분급 헛수고가 재현된다.
3. OO 과제형(빈칸 2개) 입력에 대해 **빠른 판정**이 있으면 비용이 줄어든다.

*(Mom Test 원칙: 위 가설은 STEP 2 인터뷰·추궁 답변으로 검증)*
